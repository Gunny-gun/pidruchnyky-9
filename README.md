# Підручники 9 клас — сторінка зліва, тези справа

Електронна читалкова система підручників 9 класу:
- Ліворуч — автентична сторінка підручника (WebP, оптимізовано для швидкого відкриття на телефоні/планшеті).
- Праворуч — структуровані короткі тези, ключові формули, терміни й перелік завдань саме цієї сторінки.

## Предмети 9 класу
- **Математика:** Алгебра (О. С. Істер), Геометрія (О. С. Істер)
- **Мови та література:** Українська мова, Українська література, Зарубіжна література, Англійська мова
- **Природничі науки:** Фізика, Хімія, Біологія, Географія
- **Суспільство:** Історія України, Всесвітня історія, Основи правознавства
- **Технології:** Інформатика, Технології
- **Мистецтво й здоров'я:** Мистецтво, Основи здоров'я / Безпека та добробут
